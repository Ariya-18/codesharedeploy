                            SYSTEM ARCHITECTURE
================================================================================

3-LAYER EXECUTION ENGINE:

LAYER 1: Judge0 Cloud API
  ├─ Endpoint: https://ce.judge0.com (free public API)
  ├─ No API key required
  ├─ Support: 24 languages
  ├─ Timeout: 15 seconds
  └─ Engine field: "judge0"

LAYER 2: Local Code Runner
  ├─ Method: child_process.spawn()
  ├─ Support: 10+ languages (if installed)
  ├─ Timeout: 10 seconds
  ├─ Output limit: 100KB
  ├─ Auto-cleanup: Yes
  └─ Engine field: "local"

LAYER 3: Demo Mode (Guaranteed Fallback)
  ├─ Method: Template exact matching
  ├─ Support: 24 languages (pre-defined outputs)
  ├─ Safety: No arbitrary code execution
  └─ Engine field: "demo"

FALLTHROUGH LOGIC:
  Judge0 fails → Try Local → Try Demo → "Execution Unavailable"

================================================================================
                            API ENDPOINTS
================================================================================

POST /api/execute (Protected)
  Execute code with optional input
  Response includes: stdout, stderr, compileOutput, status, time, memory, engine

GET /api/execute/engines (Protected)
  Check available execution engines
  Response includes: engines status, local compilers available

GET /api/rooms/:roomId/history (Protected)
  Get execution history for a room
  Response includes: all executions with engine field
